# igrejamult.org

Site institucional da **Igreja Evangélica Mult** — organização religiosa sem fins lucrativos (Campinas/SP).

Landing page única (`index.html`), estática (HTML/CSS/SVG), sem dependências ou passo de build.
Criada para apresentar a organização e apoiar a verificação junto ao Google para Organizações sem Fins Lucrativos.

## Conteúdo
- Missão, visão, causa, valores, prioridades e confissão de fé (base: Projeto Mult + Confissão de Fé).
- Seção de **transparência** com dados institucionais (CNPJ, natureza jurídica, situação cadastral, sede).
- Formas de participar (orar, investir, ser igreja) e contato.

## Rodar localmente
```bash
npm run dev
```
